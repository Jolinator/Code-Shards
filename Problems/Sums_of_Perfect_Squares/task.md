The task is simply stated. Given an integer <code>n</code> (<code>3 < n < 10<sup>9</sup></code>), find the length of the smallest list of [*perfect squares*](https://en.wikipedia.org/wiki/Square_number) which add up to <code>n</code>. Come up with the best algorithm you can; you'll need it!

<strong>Examples:</strong>

<ul>
<li><code>sum_of_squares(17) = 2</code> <br> 17 = 16 + 1 (16 and 1 are perfect squares).</li>
<li><code>sum_of_squares(15) = 4</code> <br> 15 = 9 + 4 + 1 + 1. There is no way to represent 15 as the sum of three perfect squares.</li>
<li><code>sum_of_squares(16) = 1</code> <br> 16 itself is a perfect square.</li>
</ul>

<strong>Time constraints:</strong>

5 easy (sample) test cases: <code>n < 20</code>

5 harder test cases: <code>1000 < n < 15000</code>

5 maximally hard test cases: <code>5e8 < n < 1e9</code>
